# eHaJo Branding

Produktname: eBauteileFuchs
Absender: eHaJo
Website: https://www.ehajo.de

## Verbindliche eHaJo-Farben

Primärfarbe: `#0b72b5`  
Sekundärfarbe: `#e67c23`

Diese beiden Farben sind unverändert zu verwenden.

## Abgeleitetes Designsystem für eBauteileFuchs

Die folgenden Farben wurden für eine kontrastreiche dunkle Anwendung aus den
beiden eHaJo-Farben abgeleitet. Technisch sind ausschließlich die zentralen
CSS-Variablen in `src/ebauteilefuchs/static/css/design-tokens.css` führend.

| Rolle | Wert | Verwendung |
| --- | --- | --- |
| Haupthintergrund | `#0b1118` | Seitenhintergrund |
| Fläche | `#111b26` | Karten und Navigation |
| Erhöhte Fläche | `#182635` | hervorgehobene Bereiche |
| Hover-Fläche | `#203246` | interaktive Flächen |
| Haupttext | `#f4f7fa` | Überschriften und Fließtext |
| Gedämpfter Text | `#afbdca` | Beschreibungen |
| Dezenter Text | `#8796a5` | Metadaten |
| Rahmen | `#304355` | dezente Trennung |
| Starker Rahmen | `#486078` | aktive Abgrenzung |
| Fokus/Link | `#72c7ff` | sichtbarer Fokus und Links |
| Link-Hover | `#a8ddff` | Hover-Zustand |
| Erfolg | `#55c994` | erfolgreiche Vorgänge |
| Warnung | `#f2b84b` | Warnhinweise |
| Fehler | `#ff7b7b` | Fehlerzustände |
| Information | `#5eb8e8` | neutrale Statushinweise |
| Deaktivierte Fläche | `#252f39` | deaktivierte Bedienelemente |
| Deaktivierter Text | `#82909d` | deaktivierte Beschriftung |

Status darf nie allein über Farbe vermittelt werden. Fokuszustände benötigen
eine sichtbare Kontur; Haupttext und Bedienelemente müssen ausreichenden Kontrast
behalten. Es werden ausschließlich lokale Systemschriften verwendet.

## Assets und Maskottchen

Das eHaJo-Logo darf nicht verzerrt, nachgezeichnet oder verändert werden.
Die Anwendung soll technisch, freundlich und für Maker geeignet wirken.

Als Browser-Favicon wird ausschließlich die bereitgestellte Originaldatei
`e_rand_t.png` verwendet. Die Wortmarke selbst wird nicht verändert.

Das finale freigegebene Fuchs-Maskottchen liegt als `fuchs-maskottchen.png` vor.
Die Originaldatei wird nicht verändert oder nachgezeichnet. Für die technische
PWA-Integration wird sie unverändert in eine quadratische SVG-Fläche eingebettet;
die Illustration selbst bleibt dabei vollständig unverändert.
