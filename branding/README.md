# Branding-Assets

Dieses Verzeichnis enthält die freigegebenen Ausgangsdateien für das
eHaJo-Branding. Das Logo darf nicht verzerrt, nachgezeichnet oder verändert
werden. Die für die Anwendung paketierte SVG-Datei unter
`src/ebauteilefuchs/static/branding/` ist eine unveränderte Kopie; ein
automatisierter Test prüft die Byte-Gleichheit.

Die Apache License 2.0 des Programmcodes gewährt keine Rechte an eHaJo,
eBauteileFuchs, dem eHaJo-Logo, einem späteren Fuchs-Maskottchen oder sonstigen
ausdrücklich als Branding gekennzeichneten Grafiken. Weitere Hinweise stehen in
`../TRADEMARKS.md`.

Es existiert noch kein freigegebenes Fuchs-Maskottchen. Bis zu einer gesonderten
Freigabe wird ausschließlich ein neutral beschrifteter Platzhalter verwendet.
