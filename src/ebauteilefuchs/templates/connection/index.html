Wenn das Smartphone keine Verbindung erhält

  1. PC und Smartphone müssen im selben lokalen Netzwerk beziehungsweise WLAN sein.
  2. Erlaube Python beziehungsweise Port {{ request.app.state.settings.port }} in der Windows-Firewall nur für private Netzwerke.
  3. Nutze keine öffentliche Router-Portfreigabe. eBauteileFuchs besitzt in Version 1 keine Benutzerkonten.
  4. Für dauerhaft gedruckte QR-Codes empfiehlt sich eine DHCP-Reservierung oder feste lokale IP-Adresse.

PWA-Installation: Service Worker benötigen laut Browserstandard einen sicheren Kontext.
