# Mitwirken an eBauteileFuchs

Danke für dein Interesse. Lies vor Änderungen `AGENTS.md` sowie die relevanten
Dokumente unter `docs/`. Verwende Python 3.12, halte Fachlogik von Web- und
Persistenzadaptern getrennt und füge zu Änderungen passende Tests hinzu.

Vor einem Pull Request müssen `ruff format --check .`, `ruff check .` und
`pytest` erfolgreich sein. Beispiele und Tests dürfen nur synthetische Daten
enthalten. Bitte committe keine Datenbanken, Backups, `.env`-Dateien oder
API-Schlüssel.

Der Programmcode steht unter Apache-2.0. Für Marken und Branding gelten die
Hinweise in `TRADEMARKS.md`.
